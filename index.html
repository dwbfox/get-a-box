          LXD endpoint
          
          
          
    
            
            
    
              Add a remote LXD host
              
              
              
              
    Generate a token on the remote server with lxc config trust add --name get-a-box. Enrollment uses the lxc client on the machine running serve.py, not browser HTTPS. The token is not saved in browser settings.
    
              
            
    
          
    
          
    
            
            
    For a remote host and trust token, use Via local serve.py → Add a remote LXD host instead. Direct mode requires a browser client certificate and an accepted server certificate; a token alone cannot establish browser HTTPS. LXD blocks cross-site writes (CSRF), so direct mode only works fully when this page shares the API origin.

          Image cache
          
          
          
    Images are keyed by release, type, profile, kernel, services, Pro token and user-data. Changing any of these (or the token) builds a new image; stale ones are pruned on connect. Cached Pro images stay attached to your subscription.
